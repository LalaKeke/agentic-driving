# 模型输出契约 2.1：明确表达未知占用

真实 GPT-6.1 试验暴露出旧输出契约的冲突：提示词要求对未知占用诚实表达，但 2.0 的 occupancy 必须为非空数组。部分响应的文字承认无法提供未来预测，结构字段却仍出现未获支持的包络。T1 因无界未知/尺度或不确定界限缺失而拒绝，未产生执行轨迹；不能把这些包络直接当作有效预测评分。

保留 agent_output_v2.schema.json 和 driving_v2.txt 原字节及含义，新增 agent_output_v2_1.schema.json / driving_v2_1.txt。设置 `DRIVING_OUTPUT_CONTRACT=2.1.0` 才启用新契约；默认仍为 2.0.0，既有真实四例条件不变。

唯一新增表达能力是 `objects[].occupancy = null`：模型明确缺少可支持的整区间未来占用。非 null 数组仍表示原有整区间车身包络，单位、坐标、时间、备选假设和不确定性含义不变。不使用当前位置复制、占位矩形、零速度或模型自报置信度补齐未知。

模型契约版本由可信适配器写入 provenance.agent_output_contract，提示词版本/哈希一同保存。未标版本的既有记录按 2.0.0 解析；未知版本拒绝。HTTP 与 Codex CLI 两种适配器使用同一显式契约选择。

物理场景仍是 2.0.0 / convex_disk_bicycle_v2：2.1 的未知状态不会被构造成可执行场景。T1 对未知占用返回 OCCUPANCY_UNKNOWN / tool_infeasible；尺度、道路或无界未知更早阻塞时仍返回对应失败。只有完整非 null 占用满足全部原有规则时，才能生成原物理场景。因此没有放宽 T2–T4 的安全要求，没有把默认数值或 GT 送入运行时。

G2 新指标版本 `g2_availability_v2` 将可评价性与误差区分：未知占用、未知不确定界限或缺失时间覆盖时，完整窗口面积覆盖为 null；另记 expected_intervals、supplied_time_intervals、evaluable_intervals 和 occupancy_status。只有整个评价窗口都可评分才报告 minimum_interval_area_coverage；部分可评分区间的最小值单独存放，不能冒充完整五秒覆盖。旧的“缺失直接记零”含义不与新结果混用。输出保留 metric_version，不应用未审定阈值。

G2 支持独立真值文件中的 record_associations：重复调用的目标 ID 可能变化，离线审阅按 record_id 对应到稳定 GT instance。不能通过最小化位置残差挑选对应关系；重叠人物或合并对象无法唯一定位时，保留未评分原因。带反馈修订的输出不计入无条件重复稳定性。

当前四例原格式试验和新格式复核属于不同实验条件，必须分开报告。新格式让未知表达忠实，不等于米制 grounding、未来占用可靠性或完整闭环已通过。

离线审阅发现模型明确称某些矩形为 unsupported placeholders 时，可通过独立真值审阅文件的 unsupported_occupancy[record_id] 列出相应 GT actor ID。G2 保留 raw_minimum_interval_area_overlap 和 mean_raw_envelope_area_ratio 作为原始几何诊断，但该占位结果不记为可用预测。排除理由与原模型文字一起保存，不删除原响应、不隐藏原始覆盖值，也不将审阅内容送回驾驶智能体。
