# G2：模型米制 grounding 可行性评价

本入口独立保留。现有 fixture 与 HTTP mock 单测不构成 G2 结果。必须准备真实图像、多帧采集记录、真实模型原始结构化输出和独立米制真值。原始数据集不打包进仓库。本服务器 nuScenes 的真实样例、隔离真值导出及运行方法见 [nuScenes 接入说明](../experiments/nuscenes/README.md)；目前没有认可的通过阈值。

先依据 capture_v2.schema.json 制作 capture JSON，包含实际图像路径（相对当前工作目录或绝对路径）、帧 ID、采集时钟、参考 time_id、自车状态、车辆尺寸、导航意图、网格与安全配置。禁止把离线真值或外部地图环境事实写入 capture。线上可配置模型仅支持 Chat Completions 风格图像输入；服务/模型必须实际支持相应能力。显式设置 DRIVING_OUTPUT_MODE 为 json_schema、json_object 或 prompt_json，后两者也必须通过本地严格 Schema 校验。不自动降级或换模型。HTTP 400/401/403 立即报错，408/429/5xx 与网络故障才有限重试。超时及重试次数有上限。没有 key 时只返回配置缺失错误，不生成虚假的模型记录。

```bash
cd implementation
export DRIVING_API_BASE=https://api.openai.com/v1
export DRIVING_MODEL=your-accessible-vision-model
# 在本地安全注入 DRIVING_API_KEY，不写到命令历史、仓库或日志。
../.venv/bin/python -m agentic.cli online --capture /path/to/capture.json --sample-id sample01 --calls 3
# 如需运行四工具与模拟短前缀，加 --plan；工具失败将反馈给模型，最多修订两次。
```

每次输出保存为 runs/<run-id>/*-model-record.json，包含 sample_id、output、provenance。可以不运行 T1 就保留失败或有未知值的真实模型假设用于 G2，避免仅评价规划成功的样本。--plan 的结果用于闭环测试；G2 使用不加 --plan 的记录。多样本逐个调用，同一 sample-id 的重复调用用于稳定性评价。

将真实米制真值独立存放到运行时目录之外（例如单独实验数据目录）；格式参考 examples/v2/truth_template.json，但模板里的虚构数值不能当作真值。人工审定模型目标与真值目标的 ID 关联，记录位置、速度、道路多边形和整区间真值占用包络，所有值必须使用相同参考帧与采集 time_id。真值中的图像哈希必须与输出记录精确一致。遮挡与场景类型由离线标注提供；距离分层边界是实验配置，范例的 10/20/40 米不是验收门槛。

```bash
../.venv/bin/python -m agentic.cli g2 \
  --records runs/<run-id>/*-model-record.json \
  --truth /separate/offline-truth.json \
  --config examples/v2/g2_config.json --out /tmp/g2-result.json
```

评价器仅在 g2 子命令中导入；adapter、T1–T4 和闭环不导入真值模块，也无真值参数。G2 拒绝 synthetic_fixture 来源、无图像哈希、时刻/坐标不匹配。来源标签和哈希提供追溯关系，不防止恶意伪造文件；真实模型调用应保留受控实验记录。

实际计算：位置欧氏误差；速度向量误差；道路边界 Hausdorff 距离；真值每个区间包络在预测备选占用并集（加模型 uncertainty）内的面积覆盖比例，报告各区间最小值；按距离、遮挡、场景类型分组；同一样本目标的重复输出位置标准差。缺失位置/速度/匹配单独计数并记 null，不能当零误差。占用时间不覆盖真值区间记覆盖零。区间面积比例是包络包含的几何诊断，不是概率、时间占比或真实连续轨迹的安全证明。多个备选并集可能很大；应同时人工审阅保守程度。单一重复调用无法计算稳定性，返回 null。

输出状态始终为 measured_no_acceptance_claim，不应用未经审定的阈值，不宣称 G2 通过。正式实验需事先确认数据集、标注精度/同步、采集标定、评价窗口与距离遮挡分层、重复次数、缺失/误检处理和各项通过标准。当前缺少真实数据及认证，尚不能验证模型的绝对尺度、运动估计或未来占用覆盖可靠性。

当前评价新增 `g2_availability_v2`，未知不确定界限和缺失未来覆盖不再混作数值准确率，详见 [模型输出契约2.1](模型输出契约2_1.md)。历史格式及原测试保留，真实旧/新提示词条件分开评价。
