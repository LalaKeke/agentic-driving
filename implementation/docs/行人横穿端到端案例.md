# 行人横穿端到端案例

## 测试性质

全部图像引用、驾驶决策、目标状态和未来占用均为**人工构造的测试替身**；没有在线调用基座模型，没有真实图像处理，也没有执行车辆控制。人工行人运动只用于生成测试输入，运行时工具不会用速度重新预测行人。

目的：验证四个工具的数据连接、约束传播、独立核验、失败反馈与新场景版本切换。不能用该案例宣称模型理解图像或完成米制 grounding。

## 初始条件

| 项目 | 数值 |
|---|---|
| 采集参考时刻 | 100 秒 |
| 自车中心、速度 | 原点，6 米/秒 |
| 车身尺寸 | 前后各 2.3 米，半宽 0.9 米 |
| 已知道路 | 纵向 −5 至 40 米，横向 −2 至 2 米 |
| 行人位置 | 前方 18 米、右侧 3 米 |
| 人工占用来源 | 向左 1.5 米/秒的测试运动；每段直接给出整区间矩形 |
| 目标包络 | 纵向半长 0.4 米、横向半宽 0.35 米，位置不确定性额外 0.2 米 |
| 决策 | 保持车道、停车让行，自车中心不超过前方 12 米，4 秒内停车 |
| 规划窗口与间距 | 未来 5 秒，每段 0.2 秒，要求间距 1 米 |

## 分支一：正常让行

1. 脚本提供智能体的停车让行决策与环境假设。
2. T1 检查来源、时刻、证据、占用覆盖，生成统一场景。
3. T2 生成各区间自车中心允许区域，计入车辆尺寸、占用不确定性和安全间距。
4. T3 在有限纵向候选中选择约 −1.5 米/秒²减速的轨迹，4 秒后前进 12 米并停车。
5. T4 独立检查整条轨迹；本次运行最小包络间距约 3.271 米，通过并释放 0.2 秒前缀。

这 12 米是自车中心位置，上沿车头位于前方 14.3 米；不能把 12 米误认为车头停止位置。

## 分支二：故障注入与反馈重规划

在正常 T3 输出之后，测试程序**故意替换**为保持 6 米/秒的匀速轨迹。这不是声称 T3 正常情况下会输出违反其硬约束的轨迹，而是测试 T4 对优化器/传输错误的独立防线。

- T4 检出：`OBSTACLE_CLEARANCE`、`STOP_BOUNDARY`、`STOP_DEADLINE`、`CORRIDOR_BOUNDARY`。
- 核验失败，释放执行前缀为零。
- 脚本模拟驾驶智能体收到反馈，保留让行行为，把停车参考点上界改为 10 米，场景修订号更新为 1。
- 同一组图像与环境假设可保留，但 T1 重新生成同版本场景，之后重跑 T2–T4。
- 新轨迹约以 −2 米/秒²减速，3 秒后前进 9 米停车，T4 通过。

脚本修订策略不属于工具；未来在线实验应由真实驾驶智能体读取反馈并产生新决策。

## 分支三：新观测确认行人离开后起步

本分支接正常停车分支，不接故障修订分支。由于没有执行器和传感器，测试直接构造正常轨迹在第 4 秒停车后的新观测：

- 新参考时刻 104 秒，修订号 2，自车中心重新设为原点，速度为零。
- 行人相对新自车中心位于前方 6 米、左侧 3 米；道路纵向范围相应变为 −17 至 28 米。
- 新的人工场景假设覆盖未来 5 秒，不能继续使用旧的未来占用表。
- 脚本模拟智能体输出 `resume`，期望速度 3 米/秒，停车上界和截止时刻为 `null`。
- T1–T4 重新运行：当前求解权重选出 0.5 米/秒²的平缓起步轨迹，5 秒前进 6.25 米，速度达到 2.5 米/秒；T4 通过，释放前 0.2 秒。

期望速度为软目标，因此未必在 5 秒内恰好达到 3 米/秒。每轮仍有显式智能体决策，无调用/跳过门控。

## 回放文件与验收

| 文件 | 用途 |
|---|---|
| `examples/pedestrian_crossing.request.json` | 初始模型替身输入 |
| `results/normal.trace.json` | 初始 T1–T4 全部请求与响应 |
| `results/fault_injection.trace.json` | 注入故障、T4 反馈 |
| `results/agent_revision.request.json`、`agent_revision.trace.json` | 智能体修订替身与重规划 |
| `results/agent_revision.provenance.json` | 明确修订来自脚本替身 |
| `examples/pedestrian_clear_resume.request.json` | 行人离开后的新观测与起步决策 |
| `results/pedestrian_clear_resume.trace.json` | 新一轮全部工具请求与响应 |
| `results/summary.json` | 机器可读预期结果汇总 |

验收要求：两次停车和起步的正常结果通过，故障结果拒绝且执行量为零，全部消息符合 Schema，跨轮引用不混用。真实模型的 G2 实验仍需另外准备图像与离线真值，测量位置、速度和区间占用覆盖误差。
