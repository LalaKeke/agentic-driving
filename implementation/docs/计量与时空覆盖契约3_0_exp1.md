# 实验契约 3.0.0-exp1：计量语义、状态对齐与整区间覆盖

这是显式新实验剖面，不修订旧 2.0/2.1 字段含义，不转换历史模型响应。输出契约 `3.0.0-exp1`、提示词 `driving_v3_exp1`、覆盖剖面 `whole_interval_sources_v3_exp1` 分别记录。默认输出契约仍为 2.0.0，旧提示词及 Schema 原字节保留。新契约的表达能力和人工测试结果不构成在线成功率改善证据。

## 坐标、身体与计量定义

| 量 | 本剖面唯一含义 |
|---|---|
| 自车坐标 | `ego_at_reference`：可信采集参考时刻自车车身中心为原点，+X沿该时刻车头，+Y向左，随后轴固定不随车转动；单位 m、s、rad |
| 自车模型点 | 运动学自行车位于后轴；中心=后轴+`d*[cos(yaw),sin(yaw)]`，`d=center_to_rear_axle_m`；轨迹及 target_region 仍描述中心 |
| 既有 d=1.2m | 原车辆参数假设；nuScenes 原生后轴位姿加该偏移得到采集中心和标定原点，工具中心/后轴转换使用同一 d；不是本轮测得值，不用于平移目标身体点 |
| 目标 position_m | 目标有向三维身体包围盒几何中心投影到地面后的 XY，即 annotation box translation XY 的对应量；不是近端保险杠、脚点或群体代表点 |
| 目标 velocity_mps | 绝对地面速度，仅旋转到上述固定参考轴，不减自车速度；不是车随动坐标中的导数。未知允许 null，不能补零 |
| body_geometry | 以目标 position 为中心的有向矩形，length_m/width_m 为全尺寸，yaw_rad 为参考轴下朝向；包围真实身体的条件假设，不含 ego 或安全间距 |
| 源占用集合 | 指定情景在整个闭源区间的名义 BODY 并集包络，包含身体大小及该情景内运动范围；不是中心点轨迹 |
| 残差 | alignment.residual_m 为状态对齐误差项；source.residual_m 为未含对齐项的几何残差；object.uncertainty_m ≥ 两者之和，物理工具仅膨胀这个总半径一次 |

占用几何不能用中心和速度由工具重新预测。初始名义身体矩形须已经包含于 t=0 的各情景名义包络中，不能用巨大残差修补名义身体不一致；这项检查不能证明未来包络真实。道路的不确定性仍独立表示，ego 尺寸和安全间距仍只由既有物理工具加入。所有有限范围均为条件假设，不是校准误差界或概率。

## 证据时间与状态时间

对象 `frame_ids[i]` 与 `time_ids[i]` 必须一一对应真实采集记录，并且模型声明该图中确实观察到该对象。工具能核对记录引用和模型声明的一致性，不能用几何检查证明图里真的看见了它；该语义仍待独立图像评价。

`state_time_id` 单独标识模型原生状态所属时刻，必须等于可信参考时刻。陈旧状态不会由工具外推。`alignment.evidence_positions` 是模型在各实际采集时刻给出的同一身体点估计，已表达于固定参考轴，不能把 ego 补偿当作目标动态对齐。

- `direct_reference_observation`：所引用证据均位于精确参考时刻，状态与观测位置在残差内一致。
- `model_motion_bound`：异步证据必须给模型原生参考状态、max_speed_mps、displacement_bound_m、覆盖全部声明情景的运动界及前提，覆盖最旧采集至参考时刻。逐项检查距离 ≤ min(位移界,速度界×实际帧龄)+对齐残差。

这只是模型条件运动界的相容性校验，不产生新的目标预测。不能靠“只差几毫秒”豁免，不能只做 ego 补偿，也不能添加没有看见对象的前向参考图像。

## 前提、类型化未知和情景

`hypotheses.premises` 使用 ID 绑定 object_ids、scenario_ids、相对参考时刻的时间区间和 space_polygon_m。不同情景可以有各自前提，不强迫单条分支前提适用于其他分支；但每个实际使用的对象、情景、源时间和名义几何必须被相应前提覆盖。空间域是名义条件几何的适用域，残差单独外包，不把域作为物理占用裁剪器。null 空间域表示明确的全域适用假设，不表示该空间已经被观测。

`hypotheses.unknowns` 同样绑定对象、情景、空间与时间；区分没有提供信息、当前表达不可承载、多个条件情景、不能给有限界。精确 enum 以新 Schema 为准。前三类中“多个条件情景”仅在每个模式都完整有界时可进入工具；其余未解决记录继续拒绝，**没有相关性裁剪**。自由文本保留说明，但不授权规划。未知空间源区不自动解释成未来 BODY 包络。

| kind | 含义 | 当前工具处理 |
|---|---|---|
| `not_provided` | 所需量或覆盖没有提供 | 明确拒绝 |
| `not_expressible` | 模型认为当前剖面无法承载 | 明确拒绝，不替模型改写 |
| `multiple_conditionals` | 多个条件情景均已提供 | 仅在绑定/前提/全部模式完整覆盖后保留所有分支 |
| `no_finite_bound` | 无法给出有限覆盖界 | 明确拒绝，不按距离忽略 |

每对象声明 scenarios 和 scenario_inventory_complete，至少保留一个合理不利模式。每个声明模式均须有完整未来包络，漏掉其中一个即拒绝。软件能检查声明内是否丢分支，不能证明模型未漏报整个现实模式；完整性布尔值不是现实完整性的认证，输出与后续结论都保留此条件。

## 粗源区间到物理网格

新 occupancy 的每条源具有唯一 ID、`kind=whole_interval_body_envelope`、status、闭区间、原始证据、前提、几何残差和 `(scenario_id,polygon_m)` alternatives。允许一个受支持的 [0,H] 包络，也允许多个覆盖整个时域的粗区间。

先逐情景检查源区间并集从 0 严格覆盖 H，不允许正时间缺口，不能以浮点小容差抹去缺口。将源细化到固定 0.2s 等工具网格时，每个闭 cell 收集所有与其相交或接触边界的源，原 polygon 保持原值、全部 alternatives 保留。若源边界位于 cell 内，会取两侧集合的并集；只接触边界的源也保留到相邻 cell，可能更保守但不会缩小集合。

不插值新多边形，不用速度平移源，不平均情景；残差总半径只应用一次。trace 记录原输出、源区间/证据/前提/场景和 cell 映射，T4 从原 trace 重建并比对物理场景，再独立核验运动与碰撞。

null、缺段、瞬时集合、placeholder、缺尺度、缺运动对齐界、遗漏声明的合理不利模式均拒绝。结构校验不能判断模型假称“supported”的多边形是否有真实依据，因此也不宣称认证了模型预测。

## 物理接口与迁移边界

新 T1 原生校验后，显式降低到既有 `convex_disk_bicycle_v2` 物理表示；旧 metadata/scene/trajectory Schema 不改含义。`scene.provenance.agent_output_contract` 保持新版本；`metric_contract_trace` 保留完整新输出和转换追溯，`output_digest` 仍指原模型输出。T2/T3/T4 和执行回执绑定完整 scene_digest，新旧轮次、坐标或源内容不得混用。

降低是新契约已支持集合的确定性表示转换，不是旧响应迁移，也不补充环境事实。旧 2.0/2.1 数据默认仍走旧 T1；拿旧响应改 provenance 为新版本会被新 Schema 拒绝。历史 27 响应只复查旧拒绝谓词，不生成任何新在线成功。若未来另做迁移分析，必须单列变更前提与逐字段转换，不能纳入旧实验分子。

## G2 可比性与评价域

确认性位置对照必须在模型和独立 GT 都声明上述身体点、固定坐标轴、采集参考及相同中心偏移后进行；GT 将注释 translation 转换到同一原点/轴。速度还须说明 GT 的时间含义：约 2Hz 注释位置差分是区间平均代理，不能自动作为模型参考时刻的瞬时绝对速度真值。语义不明或不一致时拒绝评分，保留 null 和具体原因。

道路 local patch 与地图全部 drivable extent 不是相同评价域；没有明确匹配边界与域就不输出路缘准确率。未来占用须分别给覆盖、面积膨胀和规划可用性；未运行相关工具时规划可用性为未评价，不能由高覆盖推定可规划。注释线性 BODY surrogate 必须保留代理标记，不称真实连续占用。GT 始终只在离线模块读取。

旧输出缺少这些定义，继续标记语义不可比；已有假设下探索对照保留原字节，不追写为准确率。新评价入口保留缺失、未匹配、唯一窗口数、重复响应与服务无响应的分母边界，不设未经确认的通过阈值。

## 输出保护与本轮限制

所有新评价/离线验证命令必须指定全新输出目录；目标存在、属于旧封存结果树或祖先包含 SHA 封存标记时停止。评价输入与输出分离，不在原 g2 目录刷新来源。源代码修复不改写任何旧 manifest。

本轮没有真实模型调用，没有认证探测，也不启动真实实验。后续真实实验需重新冻结新契约、提示、样例和接受条件并获得确认；提案保持 launched=false。
