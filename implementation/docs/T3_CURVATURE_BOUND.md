# T3 连续弧线约束的曲率误差界

这项修复只替换几何充分条件，不修改道路/碰撞/停车硬要求、车辆外形、安全间距、目标占用或独立 T4。真实模型实测组在此修改之前已冻结完成，不能把工程回归通过混作在线成功率。

原实现将每个后轴端点对所有半平面都内缩 `L/2`，L 为本段弧长。这个近端点距离界有效，但即使直线也会横向内缩。自车6m/s、步长0.2s、最大刹车3m/s²时，首段最短 L/2=0.57m；目标中心区 y±1.5m 经既有参考点保守转换后只剩后轴 y±0.3m，因此原优化器必不可行。相同场景的精确匀速直线经原 T4 为 PASS。

## 全区间充分条件

令后轴曲线以弧长 s 参数化，区间 s∈[0,L]，曲率 k 在区间内为常数。则：

- `||r''(s)|| = |k|`。
- 向量线性插值误差界给出 `||r(s) - chord(s)|| <= |k| L² / 8`，整个区间成立，不依赖时间均匀或转角小于π。
- 对单位法向半平面 `n·r <= b`，弦上最大投影不超过两端最大投影。因此两端均满足 `n·r_endpoint + E <= b` 且 `E >= |k| L²/8`，即可覆盖整段后轴曲线。
- 本运动模型的速度在段内线性，节点速度非负保证弧长参数单调；常加速度改变时间参数，不改变上述空间误差界。

实现取 `E = sqrt(k² + 1e-20) L² / 8`，单位 m。它平滑且不小于精确界，便于 IPOPT；理想直线界为0，实际保留1e-10 (1/m)平滑项对应的极小保守余量。T2生成单位法向，并已包含原车身圆、模型不确定范围、安全间距和中心参考点转换，不能重复膨胀或扣除。

T4依然从原始场景独立重算动力学、整区间占用与扫掠，不读取优化器可行状态作为依据。它保留旧的更保守扫掠，因此仍可能误拒贴边轨迹；当前并未将其放宽成只看采样点。

## 实际验证

[合并前实际对照](../results/process_recovery/chord_premerge_tests.txt) 包括旧源码临时副本求解不可行、新副本求解成功和未改T4通过。源码补丁与SHA保留，不改旧运行。

永久测试 `tests/test_t3_chord_bound.py` 使用真实CasADi/IPOPT、独立圆积分公式以及原场景T4：

- 窄目标区直线优化通过，末中心约30m，释放0.2s。
- 实际曲线优化的5025个独立积分点均满足原半平面；这是数值交叉检查，不代替上面的全区间推导。
- 15075次带正/负曲率、零长度与大转角的插值误差比较通过。
- 全尺寸车碰撞与采样间碰撞仍拒绝，释放0；已停在闭边界仍通过。

全部是明确人工工程测试，不是新视觉场景、在线模型或 G2 通过证据。
