# G2 计量语义实验入口与证据写保护

这是离线评价入口。导入或执行不会调用模型，也不向运行时工具提供 GT。`agentic.g2_metric` 是 `3.0.0-exp1` 的严格计量入口；原 `agentic.g2.evaluate` 保留旧数学函数供历史软件兼容，但旧定义不明的值不能经该函数包装成确认性准确率。`agentic.cli g2` 现选择严格入口。

## 比较定义

模型须原生声明输出契约 `3.0.0-exp1`，`prompt_version` 与输出版本分别保留；不能将旧响应加标签后当作新模型结果。计量语义与运行时同为：参考时刻自车车身中心固定坐标，X 向前、Y 向左；目标位置是注释 box 中心的地面 XY；目标速度是绝对地面速度，仅旋转到固定参考坐标轴，不减自车速度。GT 必须显式声明相同语义、单位、真实图像 SHA、采集参考 ID/秒、自车中心相对后轴偏移及评价域。

`record.capture.vehicle.center_to_rear_axle_m` 必须等于 GT 的 `ego_center_to_rear_axle_m`。已有 1.2m 只作为原采集/车辆配置偏移使用，不能给模型或 GT 另换偏移来减少误差。GT 当前 actor 状态必须声明 `state_time_id`；缺失/错时刻不评分。

速度还要求 GT `velocity_time_semantics="instantaneous_at_state_time"`。nuScenes 相邻约 2Hz 注释中心之差得到的斜率只能标记为 `bracketing_annotation_displacement_slope` 或其他如实描述的代理量，严格入口不会将它评分为参考时刻瞬时速度准确率。近静止自车也不补足语义定义。

速度所在的评价域也必须可确定：GT 当前位置必须有值、合法且位于已冻结域内；位置未知或域外时，速度差值拒绝评分。当前量不可评不自动阻止独立的整区间身体包络评价，后者按自己的时间、几何和域检查。

道路旧/新原生字段目前只提供模型支持的局部可行 patch，没有与 GT 一一对应的路缘、边界类别和评价域。严格入口保留 `road_available`，返回 `MODEL_ROAD_SCOPE_AND_BOUNDARY_CORRESPONDENCE_UNDECLARED`、`road_accuracy_score=null`，不把整个地图 drivable-area 与局部 patch 的 Hausdorff 称为路缘准确率。确认性道路评价仍需预先定义可对应的道路数量及支持域。

## 输入结构

每个 record 必须包含 `sample_id`、原 `record_id`、`capture`、原生 `output` 与 `provenance`。真实评价要求 `source=online_model`、图像 SHA、原输出 digest；没有秘密认证输入。人工算术测试只能在 Python 里显式 `allow_synthetic=True`，结果标记 `SYNTHETIC_NUMERIC_TEST_NOT_G2`，CLI 不提供该开关。

GT 的基本结构如下；数值示意是接口说明，不是实测 GT：

```json
{
  "samples": {
    "sample_id": {
      "measurement_semantics": {
        "coordinate_frame": "ego_at_reference",
        "origin": "ego_body_center_at_reference",
        "axes": "x_forward_y_left_fixed_at_reference",
        "actor_reference_point": "annotation_box_center_ground_xy",
        "velocity_semantics": "absolute_ground_velocity_in_fixed_reference_axes",
        "uncertainty_semantics": "noncalibrated_total_residual_radius_once"
      },
      "units": "m_s_rad",
      "coordinate_frame": "ego_at_reference",
      "reference_time_id": "real_acquisition_time_id",
      "reference_time_s": 100.0,
      "ego_center_to_rear_axle_m": 1.2,
      "image_sha256": {"frame_id": "original_image_sha256"},
      "evaluation_domain": {
        "id": "preregistered_domain_id",
        "polygon_m": [[-10,-10],[50,-10],[50,20],[-10,20]],
        "purpose": "current_actor_and_future_body"
      },
      "velocity_time_semantics": "bracketing_annotation_displacement_slope",
      "future_body_semantics": "annotation_linear_body_surrogate",
      "scene_type": "declared_scene_group",
      "objects": [{
        "id": "stable_gt_instance",
        "state_time_id": "real_acquisition_time_id",
        "position_m": null,
        "velocity_mps": null,
        "occupancy": null
      }]
    }
  },
  "associations": {
    "original_record_id": {
      "model_actor_id": {
        "gt_id": "stable_gt_instance",
        "status": "unique_reviewed",
        "evidence": ["frozen_appearance_camera_label_review_reference"]
      }
    }
  }
}
```

`config` 必须含正的 `evaluation_horizon_s` 和与 GT **完全相同**的 `evaluation_domain`。不按位置残差优化身份关联；每响应一个 GT instance 不能重复对应多个模型对象，重复者全部停止计分。缺失、未匹配、不明语义和域外目标仍在声明对象分母；另列全部 GT actor 行、原响应数与唯一窗口数。重复窗口/修订不当作独立样本；分输出契约、窗口、场景报告。

未来 GT `occupancy` 是有序、无缝、显式 `kind="whole_interval_body_envelope"` 的整区间 `polygon_m`，须完整覆盖评价时域。`future_body_semantics` 必须说明是真实整区间身体界、注释线性身体代理量还是人工测试。当前状态缺失不自动阻止独立未来包络对照。

## 未来覆盖和规划可用性

比较全部粗源区间和所有声明情景；闭边界相交的源集合全部保留，不根据速度新预测、不缩小集合。残差满足 `source.residual_m + alignment.residual_m <= object.uncertainty_m`，只添加一次总 residual；不加自车车身或安全间距。报告覆盖、包络面积膨胀和每段源 ID。null、时间缺口、占位/瞬时冒充、漏情景、缺尺度或残差冲突不产生完整覆盖分数。

每个源可以只承载部分情景，但每个声明情景必须跨其所有源严格覆盖评价时域；某一情景的时间洞不能被另一情景的源填补。模型和 GT 的任何正时间缺口（包括 1e-12 秒）都拒绝；几何数值容差不用于填补时间。等值相接的闭源区间边界保留两侧完整集合。

`planning_usability` 默认 `NOT_EVALUATED`。如果输入明确附带 `planning_result={output_digest,artifacts:{T1,T2},artifact_digests:{T1,T2}}`，只校验原 artifact 的 Schema、capture、输出摘要和 scene 关系；返回的是 `REPORTED_T1_T2_SUCCESS_NOT_INDEPENDENTLY_REEXECUTED`，并不证明 T3、独立 T4 或执行通过。高覆盖不能替代规划可用性或真实连续安全。

## 只写新目录

所有输出采用目录 `exist_ok=False`、文件独占 `x`。发现输出目标已存在、属于旧结果根、祖先有 SHA 封存 manifest、指向上述目录的 symlink，或输入/输出树重叠时，直接停止，不存在 `--overwrite`。中途失败可留下新的失败输出目录；下一次必须使用另一新目录，不补写失败目录。

以下均是模板命令，须换成尚不存在的新路径。本轮工程验证不调用真实模型：

```bash
# 新版严格入口：读取已封存模型记录/GT，全部结果写新目录。
PYTHONPATH="$PWD/implementation" .venv/bin/python -m agentic.g2_metric \
  --records /path/to/read_only/record.json \
  --truth /path/to/read_only/truth_metric.json \
  --config /path/to/read_only/evaluation_config.json \
  --out /tmp/new_metric_g2_20261028_A

# 旧历史量的探索假设对照需要显式承认语义未确认，也不能刷新旧 g2。
.venv/bin/python implementation/experiments/nuscenes/t1_diagnosis_g2.py \
  --evaluate --legacy-assumption-contrasts \
  --input-dir implementation/results/t1_unknown_diagnosis/g2 \
  --out /tmp/new_legacy_contrasts_20261028_A
```

第二条不会重写旧 truth、关联或 manifest。它不是严格 G2 准确率；旧输出不补写身体参考点或速度定义。阈值仍由单独实验配置确认，所有输出均无 G2 PASS 或在线成功声明。
