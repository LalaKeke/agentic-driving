# 3.0.0-exp2 单窗口小试：独立 G2 预注册

身份审阅入口要求 `runtime/SHA256_RUNTIME_MANIFEST.json` 明确声明 `runtime_sealed=true`。原始 record 的真实路径必须位于该 manifest 的父目录内，且相对路径、文件 SHA256 和字节数全部匹配 `files` 清单。空标记、未登记 record、修改后的 record 和指向未封存树外的 symlink 均停止；不能凭一个封存文件名开始审阅。

本入口只做离线准备和身份审阅，不调用模型。小试固定原四窗中的白天样本 `ac452a60e8b34a7080c938c904b23057`；原四窗焦点 `afd097377c71479ea8349eeae83b8143` 保留。历史上已查看过该窗口、旧模型数值和非盲视觉关联，不能称为全盲或独立未见测试。

在查看本轮新模型米制数值前，先冻结参考采集 `nusc_us_1535489306412404`、原始秒值、1.2m 自车后轴至车身中心偏移及共同域 `[-5,-12]–[45,12]m`。目标身体点固定为注释 box 中心地面 XY；速度固定为绝对地面速度沿参考轴表达。位置 GT 是同 instance、间隔不大于 0.75s 的相邻注释中心在采集时刻的线性插值，只报告该参考下的位置差。注释中心差分速度是区间斜率代理量，不评分为瞬时速度准确率。

道路局部 patch 没有与完整地图可行驶区域一一对应的边界定义，不评分为路缘误差。未来占用对照使用注释线性中心和车身外接圆产生的整区间包络代理量，要求整个 GT 包络位于冻结域内，不裁剪后改变评价问题。覆盖、面积膨胀、全部情景及规划证据分别报告，不设 G2 通过阈值。

准备阶段保留全部独立 GT actor 及其缺失值。显式格式桥接只为 GT 命名已存在的定义、状态时刻和整区间语义，不向旧模型响应补字段，也不生成目标预测。GT、投影标签和身份关联不得传给运行时模型或 T1–T4。

运行结果封存后，用 `pilot_g2.semantic_view` 生成只含匿名 actor 标签、固定视觉词白名单及真实采集引用的审阅视图。它不输出位置、速度、尺寸、残差、占用、自由文字或原始 actor ID。无法由白名单保留的外观信息不会补写。审阅者只看该视图、原始被引用图像及官方 SDK 的同图像 SHA 投影；先冻结逐 actor 身份关联，再解除数值遮蔽并评分。旧 GT 标签可以作为已披露的历史知情先验，不能直接复制旧模型 ID 的匹配。

唯一匹配须有实际被引用原图中的单个目标证据；群体、歧义、错误采集引用、同一 GT 重复匹配均不评分。不按位置残差、速度或最小误差选择身份，不换原焦点。没有合法结构化输出或没有声明 actor 时，保留对应调用失败/无输出槽，不能报告零误差。

以下为离线准备模板，输出目录必须尚不存在。实际冻结时记录生成时源码 SHA、Git 提交和 dirty 状态；提交后的正式冻结不能追写为准备时已干净。

```bash
.venv/bin/python implementation/experiments/pilot_g2.py prepare \
  --capture runs/nuscenes_cases_20261027/runtime_inputs/ac452a60e8b34a7080c938c904b23057.json \
  --old-g2 implementation/results/t1_unknown_diagnosis/g2 \
  --out /tmp/new_pilot_g2_preregistration
```

`initial` 和 `revision` 是同一唯一窗口的重复观察，各自保留输出、缺失率、未匹配率、不可比原因和阶段结果。即使存在可计算的代理量差值，仍不能称真实场景安全、可靠预测、G2 通过或在线成功率提高。
