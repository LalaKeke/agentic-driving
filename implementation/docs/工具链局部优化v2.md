# 2秒局部原型：工具链 v2

显式选择 `bounded_seed_candidates_v2`；旧默认、`yaw_bounded_box_v1`、
`bounded_seed_candidates_v1` 保留。业务输出3.0.0-exp2、wire、提示词、
车辆参数、2秒/.2秒及1米安全间距不变。新旧规划结果分别存放，不能改写旧实验。

## T1：准确反馈，拒绝条件不变

BODY_ENVELOPE_CONFLICT 给出对象、源、情景、原始车身角点、外逸角点及最大
外逸距离。PREMISE_SCOPE 给出声明/要求时间区间及对象、情景或时间冲突维度。
不自动圆整朝向、扩大包络、延长前提。微小但真实的外逸仍拒绝。

## T2：源时间与有限分离方向

T1场景及其原始来源trace保持不变。新规划器重新验证trace，再从原生源选择
与每个网格单元有**正长度时间交叠**的完整BODY集合。使用Decimal(step)*index
表达网格，避免`.6000000000000001`把仅触边源当作正交叠。没有按速度外推或
插值他车，也没有缩小任一源集合、删情景、缩残差或去掉未知区域。

这与旧版“所有闭区间触边源均扩张到整格”的允许域不同，故必须显式选v2。
前提是T1已经逐情景确认有限数量、非零长度闭源对[0,H]无正时间缺口的覆盖，
每个源的几何/前提/总残差均合法。每个单元内部的覆盖源必有正长度交叠；
在单元端点，有限闭源完整覆盖其单侧邻域，至少一个保留源也闭覆盖端点。
T3对单元两端约束，T4检查每个闭单元及其连续内部；相邻单元均检查同一
过渡状态。因此端点和全部情景仍受检查，而不必将仅触边的下一源提前用于
整个前格。此保证始终以模型源的整区间覆盖假设成立为条件。null、正缺口、
占位矩形和缺少不利分支仍在T1拒绝。

每个障碍只考察最近点法向及±X/±Y五个有限方向，按参考后轴端点的最差分离
余量选择一个半平面。所有候选半平面都用完整障碍BODY、航向带内完整自车
支持函数、总残差和1米间距构造。种子交叠不再提前结束方向搜索；种子只是
初始化，不是已接受轨迹。真正初态、邻格连通、T3硬约束和T4仍必须通过。
原参考种子在v2也使用分段航向带。候选仍为五个，不做随机无限搜索。

## T3：光滑曲率界

旧`sqrt(kappa²+1e-20)`在零曲率处二阶导约1e10，可能导致可行直行种子耗尽
IPOPT迭代。v2增加每段辅助变量K，要求`0<=K<=max_curvature`、`K>=kappa`、
`K>=-kappa`，弦差余量为`K*L²/8`。它完整保持物理充分界`|kappa|*L²/8`；
K较大只会更保守。加速度、速度、转向、停车及全部空间硬约束不变，单次
IPOPT上限仍700，无静默放松或求解失败后的自动重解。

solver记录K、迭代数及arc_bound。T4根据实际控制独立积分，不信任K或求解器
状态。T3数值容差不代替T4。耗尽有限候选仍不证明全局无解；失败反馈保留全部
候选错误，并优先返回实际到达的最深阶段。

## T4与接受器

v2使用原有连续车身扫掠界、.02秒内子段、完整源BODY、总残差和1米间距。
仅按上述同一时间定义重新选择原生源，保留原始T1重建和全部不利情景；不
改成离散点核验。接受器按明确v2重建T2，再独立核验T4、前缀回执和积分。
新corridor/trajectory Schema只是原字段的显式v2选择，无新模型输出体系。

固定真实JSON的离线重规划通过不构成新增在线成功或真实世界安全证明。
人工反例只证明软件行为，不能增加真实场景分子或分母。
