# T1 拒绝响应中的独立 G2 子项评价

本目录只做离线评价。没有新增模型调用，没有把注释、地图、未来轨迹或匹配结论写回运行时。27 份响应的 T1 拒绝、此前在线严格成功 0 和原四窗分母保持原样。当前量可以部分评价，**这些数值不是全链成功、G2 通过或真实场景安全结论**。

## 真值、坐标和匹配

- 六个唯一窗口都有独立 nuScenes mini 注释和 expansion 地图。当前量不再要求目标有完整未来五秒轨迹才进入真值，因此没有用“未来轨迹幸存者”筛掉当前量。某目标在参考时刻没有同一 instance 的合法相邻注释括住时，当前量仍为未知。
- 参考时刻为冻结采集记录里的 CAM_FRONT 时间；按同一 instance 的相邻注释线性插值，注释间隔须不超过 0.75s。速度是真值注释中心的区间斜率，不能称为测得的瞬时速度。相机与注释 sample 的约几十毫秒差异没有忽略。
- 坐标沿用 `ego_at_reference`，原点为配置自车中心；从 nuScenes 原生后轴加 1.2m 配置偏移。这个车辆参考点偏移是原实验假设，不是本轮测量值。
- [逐响应关联表](associations.json) 只依据外观、相机、类别和文字语义；每个唯一匹配记录原始 frame ID、图像 SHA、相机时刻 annotation token、官方投影像素框。**审阅者是已见过数值输出的 assistant，不是独立盲审人工。** 这是事后探索性关联，不能当预注册 benchmark。
- [36 张注释投影的索引](projection_index.json) 用官方 SDK `get_sample_data` 与 `view_points` 生成；图中没有模型预测点，避免按最近误差选注释。白天群体代表位置不配单一行人；后黄卡车 cab/trailer 参考点不明确，保留未评分；直道远车没有确认的唯一注释对应，不换一个近似位置目标来评分。
- 每响应内同一 GT instance 只能对应一个声明对象。若重复，全部标 `DUPLICATE_INSTANCE_NO_SCORE`，不重复计分。本次没有此类重复。

首次离线准备和补充像素引用的第二次准备均保留在 [preparation_attempts.json](preparation_attempts.json)。两次真值及 36 张投影逐字节相同；第二次只在投影索引补充像素引用。准备阶段如实记录当时源码提交、dirty 状态及源码 SHA。最终评价的源码提交和全部数值输入 SHA 见 [evaluation_provenance.json](evaluation_provenance.json)，不把准备阶段追写成干净冻结实验。

## 道路几何的可评范围

六窗统一采用原离线 ROI `[-5,-12,45,12]m`，保留地图 MultiPolygon 与孔洞。对有值的 16 个模型名义 road patch，记录与地图 drivable-area 的 extent IoU、模型面积落在地图外的比例及 boundary extent Hausdorff：平均 IoU 0.2247，平均地图外比例 0.1593，平均 Hausdorff 25.709m。

这些是**范围差异诊断**：模型明确只给局部保守凸区域，地图却包含 ROI 内多支道路、停车区域等，二者覆盖域和道路语义不完全一致。特别是 Hausdorff 很大可以由纵向范围短产生，不能称为模型路缘偏差或车道精度。当前契约未提供可将模型边逐条对应真实路缘/车道的边界类别及作用域，因此本轮不给“真实道路边界误差”分数。若后续要评价它，需事先冻结可对应的路段/边界定义与真值标注。

## 未来占用单列

170 声明对象行中 occupancy 有值 23、null 147。按逐对象合法关联及真值覆盖进一步分开：

| 未来评价状态 | 对象行 |
|---|---:|
| 没有唯一合法 GT 关联（其中可有模型非空包络） | 119 |
| 已唯一匹配，但模型 occupancy=null | 42 |
| 已匹配且模型非空，但 GT 五秒轨迹不完整 | 1 |
| 可以和 annotation surrogate 做面积对照 | 8 |

8 条包络共 200 个 0.2s 区间；预测多个 `alternatives_m` 取并集，并只加模型给定的 residual uncertainty 半径，不添加自车或工具安全间距。真值采用同一 instance 的注释线性中心加身体外接圆包络，**不是实测连续时间占用**。原模型的条件假设仍成立与否待评；本指标不证明转向/启停等未包含模式已被保留，也不评估未匹配目标、遮挡潜在进入者或 null 对象。

这些非常宽的包络平均 surrogate 面积覆盖约 0.99865，但平均面积膨胀约 179.61 倍（最小 25.51、最大 793.49 倍）；最差单区间覆盖仅约 0.77095。高平均重叠不能当作高质量预测、校准概率或连续时间安全。所有 27 次 T1 仍然拒绝。逐区间数据见 [future_interval_rows.csv](future_interval_rows.csv)，全部对象的缺失/不完整原因见 [object_rows.csv](object_rows.csv)。

## 复现

评价只需项目 `.venv` 和已有离线真值/人工关联；不读认证，不调用模型，不调用运行时工具：

```bash
cd /data2/hzy/MAP/agentic-driving
.venv/bin/python implementation/experiments/nuscenes/t1_diagnosis_g2.py \
  --evaluate --out implementation/results/t1_unknown_diagnosis/g2
```

要从原数据重建真值和官方投影，使用一个新的输出目录；原目录已存在时 prepare 会拒绝覆盖：

```bash
MPLCONFIGDIR=/tmp/agentic-t1-g2-mpl \
PYTHONPATH="$PWD/runs/tools/nuscenes-visualization/lib/python3.11/site-packages:$PWD/.venv/lib/python3.11/site-packages" \
runs/tools/nuscenes-visualization/bin/python \
  implementation/experiments/nuscenes/t1_diagnosis_g2.py --prepare \
  --dataset-root /data/nuscenes_dataset --out /tmp/new_t1_g2_review
```

prepare 不自动生成身份关联。新的响应、窗口或目标都必须单独审阅并冻结关联，不能继承本目录旧响应 ID 的对应关系。原 four-tool/G2 代码、阈值、提示词及旧实验标准均未修改。

[评价实现与来源核对](validation.json) 检查全部 170 条原值、51 条唯一匹配、误差独立重算、36 张原图 SHA，以及原四窗与旧真值共有 49 个对象的当前位置/速度完全一致。[重复关联反例](duplicate_association_regression.json) 是明确标注的人工评价器元数据测试，验证重复 GT 身份会全部停止计分，不计在线样本。
